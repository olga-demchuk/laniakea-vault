# Laniakea Vault — Project Context

## О проекте

**Laniakea Vault** — личная база знаний (personal wiki) для накопления информации по косметологии, нутрициологии, психологии, эргономике жилых помещений и другим темам, связанным с качеством жизни.

**Философия:** Laniakea — это проект о привычках, порядке и здравом смысле. Цель: создать систему, которая помогает справляться с рутиной, освобождая место для важного.

**Владелец:** Оля (PM в Httplab, фон в математике и музыке)  
**Время на проект:** ~45 минут в день  
**Начало разработки:** ноябрь 2024

---

## Технический стек

### Backend
- **Node.js** + **Express** 4.18.2
- **JSON-хранилище** (`data/pages.json`, `data/tags.json`, `data/links.json`)
- Порт: 3000

- **Vanilla JavaScript** (без фреймворков)
- **Marked.js** — парсинг Markdown
- **SPA** через History API (client-side routing)
- Минималистичный CSS

### Инфраструктура
- **Git** репозиторий: https://github.com/olga-demchuk/laniakea-vault
- **Локальный запуск:** `npm start` → http://localhost:3000
- **VSCode** с расширениями: GitLens, Prettier

## Ключевые фичи

### 1. Вики-ссылки `[[]]`

**Синтаксис:**
- `[[Название страницы]]` — обычная ссылка
- `[[Название|альтернативный текст]]` — с кастомным текстом

**Логика:**
- Синие ссылки — страница существует
- Красные ссылки — страница не существует (можно создать)
- Парсинг на backend (`extractWikiLinks()` в `server.js`)
- Рендеринг на frontend (`processWikiLinks()` в `app.js`)

### 2. Теги

**Два способа добавления:**
1. В тексте: `#косметология #кислоты #anti-age`
2. Через форму: поле "Теги" (через запятую)

**Парсинг:** функция `extractTags()` в `server.js`

### 3. Backlinks (обратные ссылки)

Автоматически показывают какие страницы ссылаются на текущую.

**Типы связей:**
- `inline` — из текста через `[[]]`
- `related` — явные связи (пока не реализованы в UI)

### 4. Поиск

Live search по названию и содержимому (`GET /api/search?q=query`)

### 5. Markdown

Полная поддержка Markdown через Marked.js:
- Заголовки, списки, таблицы
- Код блоки
- Цитаты
- Ссылки, изображения

## API Endpoints

```
GET    /api/pages              — все страницы
GET    /api/pages/:slug        — страница по slug
POST   /api/pages              — создать страницу
PUT    /api/pages/:id          — обновить страницу
DELETE /api/pages/:id          — удалить страницу

GET    /api/tags               — все теги с количеством
GET    /api/tags/:name/pages   — страницы по тегу

GET    /api/search?q=query     — поиск

GET    /api/stats              — статистика
```

## Workflow

### Создание статьи

1. Открыть http://localhost:3000
2. Нажать "+ Новая страница"
3. Ввести название (например: "Omega-3")
4. Написать содержимое в Markdown
5. Добавить вики-ссылки: `[[EPA]]`, `[[DHA]]`
6. Добавить теги: `нутрициология, жирные кислоты`
7. Сохранить

**Slug генерируется автоматически:** "Omega-3" → "omega-3"

### Редактирование

1. Открыть страницу
2. Нажать "Редактировать"
3. Изменить текст/теги
4. Сохранить

**Live preview** показывает как будет выглядеть (справа от редактора на десктопе)

### Git workflow

```bash
# После добавления/изменения статей
cd ~/projects/laniakea-vault
git add .
git commit -m "Add article about [topic]"
git push
```

**Что в Git:**
- ✅ Код (`server.js`, `public/`)
- ✅ Данные (`data/`) — статьи версионируются
- ✅ Документация
- ❌ `node_modules/`, `.env`, `media/`

## Принципы разработки

### 1. Простота превыше всего
- JSON вместо SQLite (проще, читабельнее)
- Vanilla JS вместо React (меньше сложности)
- Локальное хранилище (нет облака, full control)

### 2. Версионирование всего
- Код и данные в Git
- Каждое изменение — коммит с понятным сообщением
- История изменений статей доступна через Git

### 3. Incremental development
- По одной фиче за раз
- Сначала MVP, потом улучшения
- Документация обязательна

### 4. Оля не программист
- Код должен быть понятным
- Документация подробная
- Инструкции пошаговые
- Claude помогает с разработкой

## Стиль контента

### Формат статей

**Структура:**
```markdown
#тег1 #тег2 #тег3

# Название статьи

Краткое определение с вики-ссылками на ключевые термины.

## Раздел 1

Содержимое...

## Раздел 2

Содержимое...

## См. также

- [[Связанная статья 1]]
- [[Связанная статья 2]]
```

**Вики-ссылки:**
- Все ключевые термины должны быть ссылками
- Не бояться создавать "красные ссылки" (несуществующие страницы)
- Постепенно заполнять базу, кликая на красные ссылки

**Стиль текста:**
- Кратко, по существу
- Без лишнего пафоса
- Структурировано (заголовки, списки, таблицы)
- Научный подход (ссылки на исследования где возможно)

### Теги

**Основные категории:**
- `#косметология` — всё про уход за кожей
- `#нутрициология` — питание, добавки
- `#психология` — психологические концепции
- `#эргономика` — обустройство дома
- `#здоровье` — общее здоровье
- `#привычки` — habit tracking, системы

**Подкатегории:**
- `#кислоты` — AHA, BHA и т.п.
- `#жирные-кислоты` — Omega-3, 6, 9
- `#anti-age` — антивозрастной уход
- `#добавки` — БАДы, витамины

## Troubleshooting

### Порт 3000 занят
```bash
kill -9 $(lsof -ti:3000)
npm start
```

### Не показывает изменения
- Перезагрузить страницу (Cmd+R)
- Перезапустить сервер
- Проверить что `data/pages.json` обновился

### Git конфликты
```bash
git status
git diff
# Разрешить конфликты вручную
git add .
git commit -m "Resolve conflicts"
```
