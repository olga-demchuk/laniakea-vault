## ✅ Реализовано в MVP

### Функциональность
- [x] **Страницы (Pages)** — создание, редактирование, удаление
- [x] **Markdown** — полная поддержка синтаксиса
- [x] **Вики-ссылки** — `[[Название]]` и `[[Название|текст]]`
- [x] **Теги** — `#тег` в тексте или через форму
- [x] **Related pages** — явные связи между статьями
- [x] **Backlinks** — обратные ссылки (кто ссылается на эту страницу)
- [x] **Поиск** — по названию и содержимому (live search)
- [x] **Редактор** — с live preview
- [x] **Статистика** — количество страниц, тегов, ссылок

### Технологии
- **Backend:** Node.js + Express
- **Frontend:** Vanilla JavaScript (без фреймворков)
- **Storage:** JSON файлы (легко мигрировать на SQLite)
- **Markdown:** Marked.js
- **Стиль:** Минималистичный CSS

### Архитектура
- **SPA (Single Page Application)** — без перезагрузки страниц
- **RESTful API** — все операции через API endpoints
- **Local-first** — все данные локально

## ⚙️ Технические детали

### Хранилище
**JSON файлы** (вместо SQLite для упрощения установки):
- `data/pages.json` — все страницы
- `data/tags.json` — все теги
- `data/links.json` — все связи

**Плюсы:**
- Не нужна установка SQLite
- Легко читать и бэкапить
- Можно редактировать вручную (для дебага)

**Минусы:**
- Медленнее при >1000 страниц
- Нет транзакций

**Миграция на SQLite:** Схема готова в `DATABASE.md`, миграция займёт ~1 час работы.

### API Endpoints
- `GET /api/pages` — все страницы
- `GET /api/pages/:slug` — страница по slug
- `POST /api/pages` — создать страницу
- `PUT /api/pages/:id` — обновить страницу
- `DELETE /api/pages/:id` — удалить страницу
- `GET /api/tags` — все теги
- `GET /api/tags/:name/pages` — страницы по тегу
- `GET /api/search?q=query` — поиск
- `GET /api/stats` — статистика

### Frontend
- **SPA** — без перезагрузки страниц
- **Client-side routing** — через History API
- **Live search** — результаты обновляются при вводе
- **Live preview** — markdown → HTML в реальном времени
