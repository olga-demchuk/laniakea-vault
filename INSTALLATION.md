# Laniakea Vault — Инструкция по установке

## Что создано

✅ Полноценное приложение MVP — локальная википедия  
✅ Веб-интерфейс с редактором и live preview  
✅ API для всех операций (CRUD)

✅ Теги с поиском и фильтрацией  
✅ Обратные ссылки (backlinks)  
✅ Поиск по названию и содержимому

## Установка

### Шаг 1: Распаковать архив

```bash
tar -xzf laniakea-vault.tar.gz
cd laniakea-vault
```

### Шаг 2: Установить зависимости

```bash
npm install
```

### Шаг 3: Запустить сервер

```bash
npm start
```

### Шаг 4: Открыть в браузере

```
http://localhost:3000
```

## Первое использование

1. **Создай первую страницу**
   - Нажми "Новая страница"
   - Введи название: "Гликолевая кислота"
   - Напиши содержимое в Markdown
   - Добавь теги: `косметология, кислоты, anti-age`
   - Сохрани

2. **Создай вторую страницу со ссылкой**
   - Создай страницу "AHA-кислоты"
   - В тексте напиши: `[[Гликолевая кислота]]` — это создаст ссылку
   - Сохрани

3. **Проверь связи**
   - Открой "Гликолевая кислота"
   - Внизу увидишь "Обратные ссылки" → "AHA-кислоты"
   - Ссылка в тексте будет синяя (страница существует)

4. **Попробуй поиск**
   - Начни вводить в поле поиска
   - Результаты обновятся автоматически

5. **Посмотри теги**
   - Нажми "Теги" в навигации
   - Увидишь все теги с количеством страниц
   - Кликни на тег → увидишь все страницы с этим тегом

## Технические детали

### Хранилище данных

**Используется JSON-файлы вместо SQLite** (для упрощения установки).

Файлы находятся в папке `data/`:
- `pages.json` — страницы
- `tags.json` — теги
- `links.json` — связи между страницами

**Можно легко мигрировать на SQLite позже** (схема уже готова в документации).

### Бэкап

Просто скопируй папку `data/`:

```bash
cp -r data/ data-backup-$(date +%Y-%m-%d)/
```

### Порт

По умолчанию `3000`. Можно изменить в `.env`:

```
PORT=3001
```

## Проблемы?

**Сервер не запускается:**
```bash
# Проверь что Node.js установлен
node --version  # должно быть >= 14

# Проверь что порт 3000 свободен
lsof -i :3000
```

**Не установились зависимости:**
```bash
# Попробуй с флагом
npm install --legacy-peer-deps
```

**Не открывается в браузере:**
- Проверь что сервер запущен (должно быть сообщение "✅ Laniakea Vault server running")
- Попробуй `http://127.0.0.1:3000` вместо localhost
